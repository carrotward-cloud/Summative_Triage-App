# Summative Triage App

This repository contains the source code and documentation for my Level 6 DevOps summative project.

## Documentation as Code
All documentation is stored directly in this repository and version-controlled alongside the application code.  
This includes:
- Project overview
- CI/CD workflow files
- Deployment configuration
- Any updates made during development

## CI/CD
- CI workflow: validates and builds the project on every push  
- CD workflow: deploys the static site to GitHub Pages
